## Results Achieved
* **Visual Transformation:** Transformed the raw HTML site into a modern, elegant, and fully styled web experience.
* **Theming:** Implemented a cohesive dark theme with a deep blue background (`#0b1a26`) and bright blue accents (`#30a2ff`), significantly enhancing the visual appeal.
* **Modularity:** Successfully separated concerns by organizing the CSS into three modular files (`global.css`, `layout.css`, `forms.css`) for better maintainability.
* **Layouts:** Applied Flexbox to structure the contact form efficiently, creating a clean vertical alignment for all inputs and a styled submit button.
* **UI Polish:** Enhanced the readability of the class schedule table using CSS styling, border-collapse, and subtle semi-transparent background colors for spanned cells.
